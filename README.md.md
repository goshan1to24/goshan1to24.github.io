# Xbox One S Контроллеры - Лендинг

![Xbox Controller Preview](images/controller-preview.webp)

Продающий лендинг для оригинальных джойстиков Xbox One S с SEO-оптимизацией.

## Особенности
- Чистый, минималистичный дизайн в стиле Xbox
- Полная адаптивность для всех устройств
- Оптимизированная загрузка (lazy loading для изображений)
- Семантическая HTML-разметка для SEO
- Корпоративная цветовая схема Xbox

## Технологии
- HTML5 (семантическая верстка)
- CSS3 (Flexbox/Grid)
- Оптимизированные WebP-изображения
- Адаптивный дизайн (mobile-first)

## Установка
1. Клонировать репозиторий:
   ```bash
   git clone https://github.com/ваш-репозиторий.git
   ```
2. Открыть `index.html` в браузере

## SEO Оптимизация
- Оптимизированные мета-теги
