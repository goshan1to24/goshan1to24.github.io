# Xbox One S Джойстики - Официальный сайт

![Логотип Xbox](images/logo.png)

Одностраничный сайт-каталог оригинальных контроллеров для Xbox One S.

## 🛠 Технологии
- HTML5 (семантическая верстка)
- CSS3 (Flexbox/Grid)
- Оптимизированные изображения
- Адаптивный дизайн

## 📁 Структура проекта
```
xbox-site/
├── index.html          # Главная страница
├── catalog.html        # Страница каталога
├── css/
│   └── style.css       # Основные стили
├── js/
│   └── script.js       # Скрипты (если есть)
└── images/             # Папка для изображений
    ├── banners/        # Баннеры
    └── products/       # Фото товаров
```

## 🚀 Запуск
1. Склонируйте репозиторий
2. Откройте `index.html` в браузере
3. Для разработки используйте Live Server (VS Code)

## 🌐 SEO-оптимизация
- Семантическая разметка
- Правильные meta-теги
- Оптимизированные изображения (lazy loading)
- Чистые URL
