# Xbox Контроллеры - Официальный лендинг

![Xbox Controller Preview](images/preview.jpg)

Полноценный клон официального сайта Xbox, адаптированный для продвижения контроллеров Xbox.

## Ключевые особенности
- **Точный дизайн** как на xbox.com/ru-RU
- **Полная адаптивность** (мобильные, планшеты, десктоп)
- **Оптимизация производительности**:
  - Lazy loading изображений
  - Минимизированный CSS
  - WebP изображения
- **SEO-оптимизация**:
  - Семантическая разметка
  - Оптимизированные мета-теги
  - Микроразметка Schema.org

## Технологии
- HTML5 (семантическая верстка)
- CSS3 (Flexbox/Grid)
- Адаптивный дизайн (mobile-first)
- Доступность (WCAG 2.1)

## Как использовать
1. Клонировать репозиторий
2. Заменить изображения в папке `/images`
3. Настроить контент в `index.html`
4. Загрузить на хостинг
